## 1. 각인사 (刻印師) — 표식·기폭 콤보 [AP 원거리 딜러]

> ⚠️ v1 피드백: "매력이 떨어진다" — 아래 매력 보강 3안 중 택(복수 가능).

### 기본 킷
| 슬롯 | 이름 | 효과 |
|---|---|---|
| 평타 특성 | 낙인 부여 | 평타가 적에게 **인장 1스택**(최대 5, 6초 지속·갱신) |
| 기본기 | 인장탄 (cd 7) | 관통 투사체 — 맞은 적 전원 인장 2스택 + 소량 피해 |
| 보조 Lv3 | 각인 확산 (cd 14) | 표적의 인장을 주변 적에게 전파 |
| 궁 Lv5 | 파문(破紋) (cd 60) | 시야 내 인장 보유 적 전원 일제 기폭 — 스택당 폭발 |

### 매력 보강 3안 (승인 대기)
| 안 | 내용 | 노림수 |
|---|---|---|
| A. 완인(完印) | 5스택 도달 시 적 몸의 문양이 **붉게 타오르며** "완인" 상태 — 받는 피해 +15%, 시전자에게 알림 핑 | 스택 쌓기의 목표 지점·시각 위협감. "쟤 터지기 직전이다"를 전장 전체가 안다 |
| B. 도미노 기폭 | 기폭 폭발이 죽인 적의 인장을 **주변 적에게 옮긴다** — 잘 쌓으면 기폭이 기폭을 부르는 연쇄 | 물량전(무한방어)에서 도미노 쾌감 — 강령술사 물량과 다른 축의 "연쇄" |
| C. 필살 낙인(궁 교체) | 궁을 단일 대상 **거대 낙인 + 3초 초읽기** 로 — 그 사이 쌓은 스택만큼 대폭발(도망treat vs 추가딜) | 전원 기폭(파문)보다 드라마·긴장감. 단 광역 정체성은 약해짐 |
| 추천 | **A + B 채택, 궁은 파문 유지** — 완인의 위협감 + 도미노 연쇄면 "매력 부족"이 해소되고 광역 정체성도 지킨다 | |

- 난투전 궁: 대파문 — 기폭이 스택당 넉백(완인 적은 피니셔급).
- 신규 상태: `h.markStacks` + 완인 플래그. 씬: 문양 데칼(스택따라 성장·5스택 발화).

## 2. 혈기사 (血騎士) — HP 코스트 시전 [**AD** 하이리스크 브루저]

> v1 "혈마법사(AP)" → **혈기사(AD)** 로 변경(유저 결정). 자기 피가 곧 탄창인 근접 기사.

| 슬롯 | 이름 | 효과 |
|---|---|---|
| 평타 특성 | 피의 대가 | 평타 피해의 8% 흡혈(코스트 회수 루프) |
| 기본기 | 혈인참(血刃斬) (cd 6, **자기 HP 6%**) | 넓은 베기 — 피해가 **잃은 체력에 비례**(최대 +60%) + 명중 수만큼 흡혈 |
| 보조 Lv3 | ⬇ 후보 3안 중 택1 (승인 대기) | |
| 궁 Lv5 | 혈우(血雨) (cd 60, **자기 HP 20%**) | 주변 광역 혈폭발 — 피해의 50% 흡혈(다수 명중=풀피 역전). AD 계수 |

### 보조 스킬 후보 3안
| 안 | 내용 | 노림수 |
|---|---|---|
| A. 핏빛 사슬 (cd 16, HP 10%) | 표적 1명과 **3초간 사슬 결속** — 서로 멀어질 수 없고, 지속 피해+흡혈. 결투 강제 | "기사의 결투" 정체성. 도망가는 적을 물고 늘어지는 브루저 본분 — **추천** |
| B. 혈검 돌진 (cd 12, HP 8%) | 짧은 돌진 — 경로 적에게 출혈(도트) + 첫 명중자에게 흡혈 | 근접 AD의 진입기 — 실용적이나 평범 |
| C. 피의 방패 (cd 18) | **잃은 체력의 40%만큼 보호막** 3초 — 코스트 없음(유일한 무料기) | 하이리스크의 안전판. 수비적이라 캐릭터 색과는 덜 어울림 |
| 추천 | **A. 핏빛 사슬** — 신선함·정체성·난투전(사슬로 절벽까지 끌고 동귀어진) 모두 최고 | |

- 난투전 궁: 대혈우 — 명중 전원 넉백 + 흡혈 초과분이 잠시 회색 체력.
- 신규 시스템: HP 코스트 시전(현재 체력 비례, 최소 1 보장) / 잃은 체력 비례 계수 / (A안 시) 사슬 결속(이동 제한 링크).
- 봇: 체력 30% 이하에서 혈우 역전 시도 — 위험 관리 로직.

## 3. 강령술사 (降靈術師) — 그림자 사역 [소환 컨트롤러]

> v2 개편(유저 결정): 영혼 조각 픽업 대신 **"처치한 상대를 그림자로 부린다"** 가 궁 정체성.
> 렌더·전투 재활용: 전투형 분신(clone combat — 본체 모습+평타)과 야수조련사 펫 AI가
> 이미 있어 "그림자 ○○"는 검증된 두 시스템의 합성으로 구현 가능.

| 슬롯 | 이름 | 효과 |
|---|---|---|
| 평타 특성 | 원혼의 손길 | 평타가 약한 암흑 추가 피해 + 내 소환물 수명 +0.4초 |
| 기본기 | 그림자 소환 (cd 10) | **그림자 병사** 1기 소환(약체 근접, 수명 10초, 최대 3기) |
| 보조 Lv3 | 그림자 쇄도 (cd 14) | 내 그림자 전원이 지정 표적에게 달려들어 물어뜯기(도약+가속) |
| 궁 Lv5 | 그림자 사역(死役) (cd 65) | **마지막으로 처치한 적 영웅**을 "그림자 ○○"(예: 그림자 궁수)로 소환 — 그 직업의 **평타를 그대로 사용**, 야수조련사 펫처럼 따라다님(수명 20초, 1기). 처치 기록 없으면 그림자 병사 3기 |
| 난투전 궁 | 그림자 반란 | 그림자 영웅의 평타가 매 타 넉백 — 원본 주인을 우선 표적 |

- 구현 재활용: 그림자 영웅 = `spawnClone` 문법 변형(모습 = **처치당한 적** 스냅샷, 어두운 틴트)
  + 펫 추종 AI(SUMMON mobile). "그림자 궁수"면 원거리 평타(BOLT — clone combat이 이미 원거리 지원).
- 처치 기록: `h.lastSlainHero = { cls, zodiacId, name }` — 막타 시 갱신.
- 씬: 회흑색 틴트 + 발밑 보랏빛 안개, 이름표 "그림자 ○○".
- 콜로세움: 병사 없어도 성립(그림자 병사는 쿨 기반) — v1의 아레나 보정 문제 해소됨.

## 4. 몽마 (夢魔) — 매혹 [제어 서포터 · 최후 순번]

> v2 개편(유저 결정): 매혹은 **스킬샷 투사체**(맞히는 실력), 궁은 **영역 지배**.

| 슬롯 | 이름 | 효과 |
|---|---|---|
| 평타 특성 | 홀린 눈 | 평타에 짧은 슬로우(매혹의 밑밥) |
| 기본기 | 매혹의 입맞춤 (cd 10) | **투사체(스킬샷)** — 맞은 적 1.5초 매혹: 홀린 듯 **나를 따라온다**(행동 불가) |
| 보조 Lv3 | 미혹의 안개 (cd 16) | 전방 부채꼴 혼란 — 잠깐 이동 방향이 뒤엉킨다 |
| 궁 Lv5 | 꿈의 영토 (cd 70) | 지정 위치에 **지배 영역**(반경 ~7, 3초) — 영역 안의 적들이 **자기 편을 평타로 때린다**(오사). 영역 밖으로 나가면 풀림(카운터플레이) |
| 난투전 궁 | 꿈결 왈츠 | 영역 안 전원이 몽마 주위를 돌며 끌려온다 — 낭떠러지 옆이면 대참사 |

- 신규 시스템: **매혹(charmT)** — applyFear 부호 반전(시전자에게 접근). **지배 영역**(zones 신규 kind 'dream' — 영역 체류 중 오사 강제, 이탈 시 즉시 해제).
- 오사 판정: 팀 판정 유지, 공격 대상만 아군으로 강제 — 킬 크레딧은 몽마에게. 전용 테스트 세트 필수(킬 크레딧·봇 표적·소환물 소유).
- 콜로세움 리스크 최고 — 아레나에서 궁 지속 반감 보정을 처음부터.
