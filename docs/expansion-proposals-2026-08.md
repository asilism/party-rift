## 트랙 A — 신규 캐릭터 2종 (하나 고르거나 둘 다)

각 캐릭터는 킷 4칸(평타 특성 / 기본기 / 보조 Lv3 / 궁 Lv5) + 역할 + 미사용 메커닉 축 +
콜로세움 리스크를 채웠다. **A안·B안 중 택1 또는 둘 다** 승인.

### A안. 각인사 (刻印師) — 표식·기폭 콤보 [추천]
> 미사용 메커닉 "표식-기폭"의 정통 구현. 콤보 손맛 = 실력 표현 폭이 큰 축.

| 슬롯 | 이름 | 효과 |
|---|---|---|
| 평타 특성 | 낙인 부여 | 평타가 적에게 **인장 1스택**을 남긴다(최대 5, 6초 지속) |
| 기본기 | 인장탄 | 투사체 — 맞은 적에게 인장 2스택 + 소량 피해 |
| 보조(Lv3) | 각인 확산 | 표적의 인장을 **주변 적에게 전파**(광역으로 스택 퍼뜨리기) |
| 궁극기(Lv5) | 파문(破紋) | 시야 내 인장 보유 적 **전원의 인장을 일제히 기폭** — 스택당 폭발 피해(5스택 = 대박) |

- **역할**: mage (AP 딜러). AP_CLASSES·SPELL_BASE/SPELL_LVL 등록. 원거리 사거리 ~11.
- **정체성**: "지금 터뜨릴까, 한 스택 더 쌓을까"의 리듬. 순간 폭딜은 세지만 셋업이 필요해 초반 약함.
- **봇 구현**: 쉽다 — 표적 인장 ≥3이면 기폭, 아니면 평타/인장탄으로 스택. `botCombatSkills` 분기 자연스러움.
- **엔진 신규 상태**: `h.markStacks`(적 영웅/병사에 스택 카운터) — 기존 도트/낙인 상태(thornBombT·vulnT) 패턴 참조. makeView에 표시 필드(머리 위 스택 점).
- **콜로세움 리스크**: 중. 2v2에서 셋업 시간이 있어 즉발 폭딜보다 완만 — ARENA_CLASS_MOD 초기값 1.0에서 시작해 4000판 보정.
- **씬**: 인장 = 붉은 문양 데칼(적 발밑/가슴), 기폭 = 문양이 깨지는 폭발. 무기 = 낙인용 붓/도장 지팡이.

### B안. 몽마 (夢魔) — 매혹 [고위험·고개성]
> 미사용 메커닉 "매혹"(적을 잠깐 아군 쪽으로 끌어오는 강제 이동). fear의 반대 — applyFear 뒤집기.

| 슬롯 | 이름 | 효과 |
|---|---|---|
| 평타 특성 | 홀린 눈 | 평타에 짧은 슬로우(매혹의 밑밥) |
| 기본기 | 매혹의 속삭임 | 표적 1명을 **1.2초 매혹** — 시전자 쪽으로 강제로 걸어온다(행동 불가) |
| 보조(Lv3) | 미혹의 안개 | 전방 부채꼴 적들에게 **혼란**(잠깐 이동 방향 무작위) |
| 궁극기(Lv5) | 꿈의 지배 | 표적 1명을 **2.5초 완전 매혹** — 그동안 그 적이 자기 편을 평타로 때린다(강제 동선+오사) |

- **역할**: support/mage 하이브리드 — 딜은 약하고 제어로 판을 흔든다.
- **정체성**: 4보스전에서 무의미(보스는 CC저항). PvP/콜로세움·디펜스 병사 상대로 빛난다.
- **⚠️ 큰 리스크**: "아군 전환" CC는 킬 크레딧·봇 표적·소환물 소유가 꼬이기 쉽다(계획 §A-2 경고).
  도발(tauntT) 인프라를 뒤집어 재사용하되, 매혹 중 그 적의 팀 판정·아군 오사 처리를 명시적으로 테스트해야 함.
- **콜로세움 리스크**: **매우 높음**. 2v2에서 1명 매혹 = 실질 2v1 — 아레나 보정 강하게 필요(전례: 강한 CC는 과평가/과소평가 양극).
- **봇 구현**: 중. 적 밀집/저체력 시 궁, 근접 시 매혹. 매혹당한 봇의 오사 로직이 관건.

**추천**: **A안(각인사)** 먼저. 콤보 손맛이 실력 표현을 넓히고, 콜로세움 리스크가 관리 가능하며,
봇·엔진 구현이 검증된 패턴(스택 상태 + 광역 기폭)이다. B안(몽마)은 매력적이지만 "아군 전환"의
시스템 리스크가 커서, A안으로 공정을 한 번 돌린 뒤 별도 신중 구현을 권한다.

## 트랙 B — 다섯 번째 보스 (2안 중 택1)

기존 4보스 축: 카르곤=충격·기동(안전지대) / 아르케인=의식·광역마법(부수기·비키기) /
녹스=은신·암살(개인 표적) / 브램블=잠식·생장(전장 관리). **빈 축 = "공간을 강제로 재배치"**.
각 안은 기믹마다 개인 실행 원칙·페이즈 스케일·봇 짝 행동을 표로 채웠다.

### 1안. 볼드 — 중력 군주 [추천]
> 축: **인력/척력** — "서 있을 자리를 빼앗는" 보스. 4보스 어디에도 없는 동사.

| 기믹 | P1/P2/P3 스케일 | 개인 실행 | 봇 짝 행동 |
|---|---|---|---|
| 특이점(시그니처) | 블랙홀 존 1/2/3개 — 반경으로 끌어당김, n초 후 폭발 | 끌리는 힘 거슬러 **걸어 나오기**(존 밖으로) | 존 반대 방향 가중 이동(botDodgeBossZone 변형) |
| 궤도 낙석 | 맵을 도는 위험물 1/2/3개(회전 반경↑) | 도는 궤도 **읽고 비키기** | 낙석 예측 위치 회피 |
| 중력 반전(P2+) | 짧게 이동 입력이 반대로 | 반전 전에 **미리 자리 잡기**(예고 후 발동) | 반전 예고 시 안전지대로 선이동 |
| 궁극기: 대붕괴 | 맵 중심으로 전원 강하게 흡인 → 중앙 대폭발 | 흡인 버티며 **가장자리로 탈출**(잠식 밖 개념) | 흡인 반대편 전력 이동 |

- **기동**: 보스가 부유하며 순간이동으로 존 사이를 옮겨 다닌다(정적이지 않게 — 브램블 잠행 교훈).
- **씬**: 중력 렌즈 왜곡 링, 끌려가는 파티클, 낙석 = 회전 궤도. 무기 = 중력구 홀.
- **신규 엔진 훅**: 흡인(applyKnockback의 반대 — 중심으로 당김). 나머지는 존/낙하 재사용.
- **티어 완충 예측**: 회피형 킷이라 티어 배율이 정직(브램블 교훈) — 전용 완충 최소.

### 2안. 제피르 — 폭풍 지휘관
> 축: **상시 풍향** — 전장 전체에 바람이 불어 포지셔닝을 계속 강요.

| 기믹 | P1/P2/P3 스케일 | 개인 실행 | 봇 짝 행동 |
|---|---|---|---|
| 돌풍 벽(시그니처) | 맵을 쓸고 가는 띠 1/2/3줄 | 오는 타이밍에 **직각 회피** | 띠 경로 수직 이탈(돌진 경고 봇 변형) |
| 폭풍의 눈 | 안전지대(눈)가 이동 — 밖은 지속 도트 | 이동하는 눈 **따라 서기** | 눈 중심 추적(안전지대 봇 변형) |
| 낙뢰 표식(P2+) | 개인 표식 1/2/3명 → 낙뢰 | 표식 뜨면 **아군과 떨어져** 혼자 맞기 | 산개(botSpreadBomb 변형) |
| 궁극기: 대선풍 | 전장 회전 강풍 — 모두 원을 그리며 밀림 | 밀림 방향 **역보정 이동** | 바람 역방향 이동 |

- **씬**: 상시 나뭇잎/먼지가 한 방향으로 흐름(풍향 시각화), 돌풍 벽 = 반투명 띠.
- **주의**: "상시 밀림"은 조작 답답함 위험 — 밀림을 약하게(이동 보정 가능 수준)해야. 폭풍의 눈이 핵심 재미.
- **티어 완충 예측**: 이동 방해가 누적되면 티어에 과민할 수 있음 — 실측 필요.

**추천**: **1안(볼드)**. 인력/척력은 4보스와 확실히 다른 동사이고, 각 기믹이 개인 실행·페이즈
스케일을 깔끔히 만족하며, 씬 연출(중력 왜곡·궤도)이 시그니처로 강렬하다. 2안(제피르)의 "상시
풍향"은 매력적이나 조작 답답함 리스크가 있어, 폭풍의 눈만 볼드의 서브 기믹으로 흡수하는 것도 방법.

### 동반 처리 권장 (B와 함께)
- **카르곤 P3 트위스트**: 4보스 중 유일하게 페이즈 진화 없음. 제안: **P3 도약 강타 2연속**(첫 착지
  후 안전지대가 새 위치로 이동 → 두 번째 강타). 승인 시 B 착수 전 워밍업으로 먼저.

## 트랙 D-2 — 웨이브 이벤트 3종 비교 (구현 시 택1~2)

무한방어 파도의 단조로움을 깨는 이벤트. **핵심 제약**: 난이도 노브(그림자 정예 수·미니언 hpMul
기울기)를 건드리지 않는 별도 레인이어야 한다(메모리 교훈 — hpMul 0.015 차이도 도달 6웨 변동).

| | ① 보물 정예 | ② 변종 파도 | ③ 선택 보급 |
|---|---|---|---|
| **내용** | 금빛 정예 1기 등장 — 잡으면 팀 골드 대량. 도망다니고, 시간 내 못 잡으면 이탈 | 특정 배수(예 7웨)에 조성 변형: 전원 원거리 / 전원 돌진 / 거대 1기 | 특정 웨이브 클리어 시 증강 대신 소모품·골드 중 택1 |
| **재미 축** | 추격·집중(딜 레이스) | 대응 전술 전환(리듬 변화) | 빌드 선택지(플레이어 주도권) |
| **구현 난도** | 중 — 새 정예 AI(도망 로직)+보상 | 낮 — 기존 파도 스폰의 조성만 변형 | 낮 — 증강 뽑기 UI 재사용(선택지만 교체) |
| **밸런스 리스크** | 낮 — 보상 이벤트(위협 아님) | **중** — 조성 변형이 특정 직업에 유불리 | 낮 — 순수 보상 |
| **도파민 지표 영향** | 큼(골드 레이스 = 짜릿) | 중(변화 자체가 환기) | 중(선택의 만족) |
| **추천도** | ★★★ 1순위 | ★★ 2순위 | ★★ 곁들이기 |

**추천 조합**: **① 보물 정예 + ③ 선택 보급**. ①이 매 판 하이라이트(골드 레이스)를 만들고, ③이
빌드 주도권으로 리텐션을 높인다. ②(변종 파도)는 직업 유불리 리스크가 있어 실측 후 신중 도입.
- 셋 다 난이도 노브와 별도 레인(정예 수·hpMul 불변) — 도달 웨이브 분포를 흔들지 않게.
- ①의 보물 정예 도망 로직은 용/이무기 enrage 패턴이 아니라 **단순 회피 이동**으로(추격 재미).
