> 힐러 꽃밭 등)까지 반영. 검증은 웹 `?ult` 궁극기 시험장에서.

> 2026-08-02. 게이지 궁극기(v117)가 깔린 위에, 각 직업 궁을 "게이지를 모은 보람이 있는
> 한 방"으로 강화하는 계획. 원칙: **기존 궁 킷의 정체성 유지 + 대난투 전용 과장**(수치·
> 연출·넉백)만 얹는다 — 본편(3v3 등) 밸런스는 건드리지 않는다(brawl 게이트).

## 0. 공용 연출 언어 (v117에 1단계 구현됨)
- 발동: 마법진 링 + 수직 빛기둥 + 화면 진동(구현됨) → **2단계: 0.25s 슬로모(시뮬 dt 축소)
  + 시전자 스포트라이트(주변 어둡게) + 발동 보이스 피드**
- 명중: 직업 색 쐐기/파열 + 강넉백은 공용 콤보 피니셔 문법 재사용
- 공수 등급: ★(수치·기존 fx 재사용) / ★★(전용 이펙트 1개) / ★★★(신규 메커닉)

## 2. 구현 순서 제안
1. **공용 2단계 연출**(슬로모+스포트라이트) — 전 직업 즉시 체감 (★ 공수로 전체 상향)
2. ★ 등급 6종(수치·재사용) 일괄 → 시뮬 밸런스 확인
3. ★★ 등급 — 판 정체성 강한 것부터(전사·탱커·검성 대기)
4. ★★★ 3종(암살자·사슬잡이·시간여행자)은 각각 별도 PR

## 3. 밸런스 가드레일
- 궁 1회 = 게이지 100(약 8~12초 교전). 판당 인당 3~5회 예상 — "필살기"지 스팸 아님
- 전원 대상 궁(번개류)은 스폰무적·별 예외 유지, 서든데스 중 게이지 충전 반감 검토
- 시뮬 게이트: 완주율 100%·판 3~5분·우승 분포 5직업+ 유지 못 하면 재조정
